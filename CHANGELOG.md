# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 - 2026-11-09

- Added native Linux unlock support for the original Samsung Portable SSD T5.
- Added authenticated `--disable-security` support without formatting or reset.
- Added exact SCSI identity validation and safe device auto-detection.
- Added hidden password entry, memory wiping, dump prevention, and self-tests.
- Validated unlock, relink, and persistent Security Mode removal on physical T5
  hardware.
